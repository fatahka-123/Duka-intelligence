# Competitive positioning

## The market today
Kenyan small-shop POS products (e.g. SimbaPOS, Uzapoint, Selly, Veira, Kyaya, Zama, JiPOS, Finytab, plus Odoo add-ons) already
sell **M-Pesa integration, offline mode, inventory, receipts and multi-user access**. Those are now table stakes: a new product
that only matches them competes on price.

## Where Duka is different
Most systems *record* what happened. Duka is built to **check, chase and explain** it — the jobs an owner does after hours.

| Capability | Typical POS | Duka v0.3 |
|---|---|---|
| Record M-Pesa payments | ✓ | ✓ |
| Block reused / unconfirmed M-Pesa codes at the till | rare | ✓ verified against Safaricom confirmations |
| Paybill debt repayments clear the right customer's balance automatically | rare | ✓ by receipt or phone, oldest debt first |
| Shift cash-up with variance per cashier | some | ✓ blind count + owner alert |
| Staff risk score (voids, discounts, shortages, write-offs, fake codes) | rare | ✓ Loss watch |
| Owner gets a nightly WhatsApp summary in Kiswahili | rare | ✓ |
| Automatic, escalating, polite debt reminders | rare | ✓ |
| Restock plan from sales velocity | some | ✓ with supplier WhatsApp order |
| Price coach when supplier prices rise | rare | ✓ |
| Anonymous area price benchmarks | not seen | ✓ opt-in, k-anonymous |
| Lender-ready score + verifiable statement link | not seen in shop POS | ✓ |
| Type or speak transactions in Kiswahili/English | not seen | ✓ |
| Works offline, idempotent sync | ✓ (some) | ✓ |

*“Rare / not seen” reflects a quick review of public product pages in Nov 2026, not an exhaustive audit — verify before using in marketing.*

## One-line pitch
**Duka Intelligence: the shop assistant that catches fake M-Pesa, chases your debts and texts you the day's profit — in Kiswahili.**

## Who to sell to first
1. **Absentee owners** (employed elsewhere, one or two shops run by staff) — loss watch, cash-up and the nightly summary pay for themselves.
2. **Shops with lots of credit customers** (mini-marts, agrovets, hardware) — automatic reminders and Paybill auto-matching.
3. **Shops seeking stock financing** — the Duka Score and verified statement; partner with a SACCO or stock-financing lender.

## Business model to test
Freemium till + paid "automation" tier (summaries, reminders, M-Pesa reconciliation, loss watch), billed via M-Pesa.
Lender referrals on verified statements as a second revenue line (needs legal review and explicit owner consent, which the link flow already enforces).
